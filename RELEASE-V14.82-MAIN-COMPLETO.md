# ThinkStore Main V14.82 · Main completo

V14.82 consolida en un único paquete completo los cambios recientes de Main. Se construyó sobre V14.80 completo y se aplicó la integración V14.81.

## Incluido

- Staff con flujo de venta presencial.
- Foto de perfil para vendedores, administradores y superadministradores.
- Tasa BCV histórica.
- Pagos mixtos USD/VES.
- Caja Staff.
- Integración financiera con Enterprise.
- Copia interna de Enterprise actualizada a V10.14.
- Dominio canónico de Enterprise: `https://enterprise.thinkstore.ve`.

## Base de datos

V14.82 no añade una migración nueva. Mantiene las migraciones anteriores dentro del proyecto para referencia. Si la base ya pasó las verificaciones de Caja Staff y Caja Chica, no se debe repetir SQL solo por instalar V14.82.
