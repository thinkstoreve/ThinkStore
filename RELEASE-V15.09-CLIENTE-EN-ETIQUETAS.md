# ThinkStore V15.09 · Cliente en etiquetas de Servicio Técnico

Base: V15.08 PAGADO SINCRONIZADO SOPORTE.

## Cambios
- La etiqueta 40 × 60 mm vertical ahora muestra **Cliente: Nombre Apellido**.
- El formato anterior horizontal 40 × 60 mm también muestra el nombre del cliente.
- El nombre se incluye tanto en la impresión desde navegador como en el PDF generado para HereLabel.
- Se conserva número de orden, equipo, color y QR de seguimiento.
- Se ajustaron tamaños y espaciado para evitar cortes en la etiqueta M1.
- Cache de Soporte actualizado a r1509 para forzar la carga de la nueva plantilla.

No requiere SQL nuevo.
