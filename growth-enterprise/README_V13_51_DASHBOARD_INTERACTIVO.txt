ThinkStore V13.51 · Dashboard interactivo

- Las 8 métricas principales del Dashboard ahora son tarjetas interactivas.
- Cada tarjeta abre una ventana independiente con animación profesional.
- Detalles disponibles: pedidos, clientes, pagos pendientes, comprobantes,
  preórdenes/tránsito, envíos/entregas, ventas validadas y clientes nuevos.
- La nueva ventana incluye buscador, resumen, datos reales del snapshot y
  tarjetas con información detallada.
- No se modifica Supabase, inventario, pedidos, pagos ni lógica de ventas.
- Base completa: V13.50.
