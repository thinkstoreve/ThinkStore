# ThinkStore Enterprise V10.20 · Control financiero ejecutivo

Base: Enterprise V10.19.

## Importante
- No elimina, reinicia ni migra valores existentes.
- No requiere SQL nuevo.
- Conserva gastos, aportes, devoluciones, ventas, comisiones, conciliaciones y cierres ya registrados.

## Cambios
- Inicio ejecutivo con ventas de hoy, Servicio Técnico de hoy, gastos, caja, cuentas por cobrar y utilidad semanal.
- Tesorería & Socios rediseñada: deuda por socio, desglose de aportes/gastos/compras/Caja Chica y devoluciones.
- Centro de gastos con filtros por periodo, categoría, quién pagó y búsqueda; soporte para referencia, notas y enlace de comprobante.
- Liquidación de Servicio Técnico por orden: cobrado, recuperación a inventario, comisiones y utilidad de empresa.
- Comisiones técnicas y de vendedores visibles por separado.
- Auditoría semanal reforzada y estado de semana cerrada.
- Responsive completo para laptop pequeña, tablet, iPad y teléfono.
- Se eliminó el LEEME heredado V10.9 para evitar confusión.

## Despliegue
Desplegar este ZIP sobre el proyecto Enterprise existente. No ejecutar SQL para esta versión.
- Pago de comisión de vendedor integrado a caja y conciliación para no dejar salidas fuera del control financiero.
