# ThinkStore Main V15.30 · Accesorios sincronizados desde Inventory

- La tienda pública lee accesorios publicados directamente desde Inventory Central.
- Corrige productos nuevos que quedaban en borrador editorial y no aparecían al cliente.
- Agrupa variantes por producto padre / colección.
- Accesorios se organiza por Cases, Cargadores, MagSafe, Cables, Vidrios y Otros.
- Silicone Case, cargadores y cables publicados aparecen sin crearlos manualmente otra vez en la web.
- La API pública solo expone campos comerciales seguros; no expone costos de compra ni proveedores.
- Mantiene compatibilidad con catalog_products y el catálogo anterior.
- No requiere SQL nuevo.
