ThinkStore Soporte V8.4
Bitácora visible para el cliente + correo de reparación detallado

NOVEDADES

1. Bitácora técnica
   - Nota interna o visible para el cliente.
   - Título de actualización.
   - Diagnóstico.
   - Trabajo realizado.
   - Repuestos / piezas utilizadas.
   - Pruebas finales.
   - Observaciones / recomendaciones.
   - Opción "Enviar correo al guardar".

2. Orden
   - El gestor muestra las últimas actualizaciones públicas.
   - El técnico puede revisar qué información ya recibió el cliente.

3. Correo
   - Nuevo diseño premium.
   - Estado actual.
   - Presupuesto / cobro / garantía / guía.
   - Bloque "Detalle de la reparación".
   - Solo incluye notas visibles para el cliente.
   - Botón al seguimiento completo.

4. Seguimiento público
   - Nueva sección "Detalles de tu reparación".
   - Historial visible publicado por el técnico.

PASO OBLIGATORIO
Antes de desplegar la V8.4 ejecuta una vez:
MIGRACION-SOPORTE-V8.4-BITACORA-CLIENTE.sql
en Supabase -> ThinkStore-Soporte -> SQL Editor.

No lo ejecutes en el Supabase principal de ThinkStore.
