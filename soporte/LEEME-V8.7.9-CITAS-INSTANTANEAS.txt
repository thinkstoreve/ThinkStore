ThinkStore Soporte V8.7.9
Correo instantáneo para nuevas citas web

FLUJO
1. El cliente crea una cita web.
2. Supabase crea la notificación appointment_new.
3. Un trigger pg_net llama inmediatamente a la función segura de Netlify.
4. Netlify envía el correo a soporte@thinkstore.com.ve usando Resend.
5. support_notifications.email_sent_at queda marcado para evitar que el resumen de 5 minutos duplique el correo.
6. El resumen programado espera un margen de 2 minutos para las citas nuevas y actúa como respaldo si el envío instantáneo falla.

VARIABLES YA UTILIZADAS
- SUPPORT_SUPABASE_URL
- SUPPORT_SUPABASE_SERVICE_ROLE_KEY
- RESEND_API_KEY
- FROM_SOPORTE_EMAIL (opcional; usa fallback actual)
- SUPPORT_NOTIFICATION_TO (opcional; por defecto soporte@thinkstore.com.ve)

PASO OBLIGATORIO
Después del deploy, ejecuta:
MIGRACION-SOPORTE-V8.7.9-CITAS-CORREO-INSTANTANEO.sql

en Supabase -> ThinkStore-Soporte.
